📲 Version 4.0.8 - Installable App, Saved Report Text, Seat Change List, Card Swipe & Chart Print Scale

Released: 18 October 2026
FEATURE Install BPM Pro (Works Fully Offline)
  • The old "Download Offline Version" button is replaced by 📲 Install BPM Pro. It installs the tool like an app, with the 💺 icon, on your phone or computer.
  • Every page is saved on the device (main tool, all seat charts, guide and version history), so everything works without internet after the first visit.
  • Nothing prompts you to install when you open the website. You choose when, by tapping the green Install BPM Pro button, which opens the browser's install window straight away. After installing it shows ✓ BPM Pro installed, and it is hidden inside the installed app.
  • A banner appears when a new version is available. Tap Update to load it.
  • iPhone/iPad show the Share → Add to Home Screen steps. If your browser does not offer the install window, the button shows the menu steps (⋮ → Install app).
FEATURE Each Report Tab Remembers Its Pasted Text
  • Switching tabs, reloading, or closing and reopening the browser puts back the exact text you pasted for that report in the input box.
  • Text you typed but did not generate yet is kept for that tab too. Pressing Clear only blanks the box; the original text returns when you come back to the tab.
  • Edits on passenger cards (Special, INF, EXT, remarks, seat) are kept when you change a setting and the report regenerates.
  • If the browser storage is full, a warning is shown instead of silently losing changes.
FEATURE Seat Change List
  • A new SEAT (n) chip sits beside INF, EXT and REMARKS. Tap it to see every passenger who was moved, shown as 11A → 20K.
  • Works for moves made from the passenger card and for moves and swaps made in the seat chart pages. Moving a passenger back removes them from the list.
FEATURE Swipe Between Passenger Cards
  • With a passenger card open, swipe to move through passengers in the order of the pasted text. It wraps around from the first to the last passenger and back.
  • A counter at the top of the card shows the position (for example 2 / 140). On a computer, use the left and right arrow keys.
  • Swipes that start on the remarks box, buttons or toggles are ignored, and anything you typed in remarks is saved before the card changes.
IMPROVEMENT Tap Outside the Card to Close It
  • Tapping the dimmed area around the passenger card closes it, so you no longer need to reach the ✕.
  • The card now scrolls inside the screen, so there is always an area around it to tap, even on small phones.
FEATURE Floating 🔍 Seat Search Button
  • Once a report is open, a round 🔍 button floats at the bottom right. It does the same as tapping the yellow flight header: open the seat keypad.
  • It is hidden when printing.
FEATURE Custom Print Scale on A330 / A350 Seat Charts
  • The View options of the A332, A333, A339, A350 and A359 charts now have a Print scale slider and a typed % box (30–150%), so you can adjust it on a phone before saving as PDF.
  • It is remembered on the device and applies only when printing. Values above 100% enlarge the chart beyond the A4 sheet.
FIX Stability
  • Seat moves into an empty seat made in a seat chart page now reach the main page (passengers are matched by ID instead of seat number).

🪑 Version 4.0.4 - 737 Business Class Row 4 Toggle

Released: 2 June 2026
FEATURE Toggle Between 3‑Row and 4‑Row Business Class Layouts
  • New button in 737 seat chart control bar to switch between 3 rows (737NG/MAX) and 4 rows (737NR)
  • When switching to 3‑row mode, row 4 is completely removed (not just hidden) to match actual aircraft configuration
  • If any passengers are assigned to row 4, a temporary warning appears in the zone summary
  • Passenger data is preserved and repopulated when toggling back to 4‑row mode
  • Works seamlessly with Aft View and font size adjustments
IMPROVEMENT Improved 737 Seat Chart Flexibility
  • Crew can now match the exact business class row count of the aircraft (3 rows for NG/MAX, 4 rows for NR)
  • Prevents confusion of seeing an extra blank row when row 4 is not present
  • "Reduces paper and ink usage by removing unnecessary rows when printing" - Fahrin
  • Regeneration logic preserves existing chart data and aft view orientation
NOTE How It Works

The 737 seat chart now has a checkbox labeled “4‑Row Mode (737NR)” – checked = 4 rows, unchecked = 3 rows. When unchecked, the seat grid regenerates with only rows 1–3. Any passengers originally seated in row 4 will not be displayed, and a warning appears. Re‑checking the box restores row 4 and all passengers. This gives crews full control to match the actual aircraft they are working on.

🎂 Version 4.0.3 - Birthday Detection displayed using 🎂

Released: 27 May 2026
FEATURE Passenger Birthday Detection
  • Detects passenger birthdays from manifest PAX DOB lines (DD/MM format)
  • Identifies birthdays on the flight date or the next day (for long-haul flights crossing midnight)
  • Adds 🎂 icon in meal column and summary counters
  • Birthday passengers automatically included in filtered reports (even without special meals or elite tier)
IMPROVEMENT Enhanced Parsing & Summary Integration
  • Added DOB_PATTERN to correctly skip date lines without affecting passenger name
  • Birthday counts now appear in Global Summary, Zone Summary, and Port/Starboard side stats
  • Seat chart also shows 🎂 next to meal (if present) or standalone for business class passengers
  • Helps crew offer card, keychain etc. on board
NOTE Birthday Check Logic

Birthday is considered valid if the passenger’s DD/MM matches either the flight date or the following day – useful for long-haul flights where the meal service may occur after midnight local time. Do note that PAX DOB column in BPM is live and only display the birthdate according to real date(today) and the day after(tomorrow).
