0. Install & Share PWA

This tool is a Progressive Web App (PWA). Installing it lets you:

  • Launch it from your home screen like a native app.
  • Share Excel files (.xlsx, .xls) or PDFs directly from other apps – the Roster Parser will appear in your Android share sheet.

How to install (Android – Chrome)

  1. Open this page in Chrome on your Android device.
  2. Look for the “Install” banner at the top of this page – tap it if you see it.
  3. If the banner doesn’t appear, tap the three‑dot menu (⋮) in the top‑right corner of Chrome.
  4. Select “Install app” or “Add to Home screen” (the exact wording may vary).
  5. Follow the on‑screen instructions – Chrome will add an icon to your home screen.
  6. Once installed, open the app from the home screen. You’ll see the same interface, but now it’s a standalone app.
💡 If you already see the “Install” button at the top of this page, tap it – that’s the fastest way!

How to use the share feature (Android only)

  1. Open any app that has a roster file (e.g., email, WhatsApp, Drive, Files).
  2. Tap the “Share” button (usually an arrow or three dots).
  3. In the share sheet, scroll until you see “Roster Parser” (or “Roster Parser · 2100551”).
  4. Tap it – the app will open and automatically parse the file.
  5. You’ll see your roster loaded instantly, ready to save, export, or find time with others.
⚠️ iOS (Safari) note: Web Share Target is not supported on iOS. You can still install the app to your home screen (using “Add to Home Screen”), but you’ll need to upload files manually via the “Choose file” button. I recommend using Android for the best experience.

What files can you share?

  • .xlsx – Excel (preferred, most reliable)
  • .xls – older Excel format
  • .pdf – works for Roster Reports or Calendar PDFs (may need manual force‑reparse)

If the share option doesn’t appear

  • Make sure you have installed the app – the share target only works after installation.
  • Clear Chrome cache and re‑install if you see duplicate entries.
  • Ensure you’re using Chrome 89+ on Android 12+.

1. Quick Start Guide 5 steps

If you just want to get started right now, follow these 5 steps:

  1. Get your roster file — usually an Excel (.xlsx) file from your airline's portal or email.
  2. Open this tool — on your phone, tablet, or computer.
  3. Load the file — drag it onto the dotted area, or tap "Choose file" and select it. Better yet: share it directly from another app after installing!
  4. Review your schedule — the table appears automatically. Use the "Fit screen" button to see all columns.
  5. Save your roster — type your name, pick a timezone, and tap "Save roster" so you can later find free time with other crew.
💡 On a phone? Tap buttons with your finger — they are sized for touch. On a PC? Click with your mouse.

2. Loading Your Roster file upload

Where to get your roster file

Your airline usually provides a roster in one of these formats:

  • Excel file (.xlsx or .xls) — the best format. Often named "Roster Report".
  • PDF file — can be a "Roster Report" (table) or a "Calendar/Fridge" view.

Download the file to your device (email, company portal, etc.)

How to load the file

  1. On a computer: Drag the file from your folder onto the dotted area. Or click "Choose file" and pick it.
  2. On a phone/tablet: Tap "Choose file" — your device will ask you to pick a file from your storage (Downloads, Photos, Files).
  3. After selecting, the file starts processing automatically. You'll see a message like XLSX or PDF · Roster Report.

Or use the share feature (if you've installed the app) – just share the file from any app and the parser will open automatically.

If the format is not recognised correctly

Sometimes the tool might guess the wrong PDF type. If you see a "Not right? force re-parse as:" section, try the other button:

  • "Roster Report table" — use this if your PDF looks like a spreadsheet with rows and columns.
  • "Calendar / fridge" — use this if your PDF looks like a monthly calendar grid.
⚠️ PDF parsing can be imperfect — if you can, always use the .xlsx version for best results.

5. Editing the Code Legend customize

The legend shows what each duty code means. You can change or add descriptions:

  1. Edit a description — tap or click on any description field (the right‑hand box). Type your own text.
  2. Add a new code — tap the "+ add code" button. A new row appears. Enter the code (e.g., STBY) and its description.
  3. Delete a code — tap the "✕" button next to the row you want to remove.
  4. Changes are saved automatically — your customisations stay on this device, even after reloading the page.
⚠️ The legend is stored in your browser's local storage. If you clear your browser history/cache, your changes will be lost. Consider this when you switch devices.

6. Saving Rosters for later use

You must save your roster if you want to use the "Find Time Together" feature. Saving also lets you keep a copy of your schedule.

How to save

  1. After your roster appears, scroll down to the "Save This Roster" section.
  2. Enter your name — any name you like (e.g., "Ikhlas", "Nadiya", or your full name).
  3. Choose a timezone:
    • SLT — your home base time (KUL / UTC+8). This is the default.
    • UTC — Coordinated Universal Time. Use this if you prefer to see everything in UTC.
  4. Tap "Save roster". You'll see a confirmation message.

Managing your saved rosters

Below the save section, you'll see a list of all saved rosters. You can:

  • View — click the View button to reload that roster and see it on screen.
  • Delete — click the Delete button to remove it (this can't be undone).
  • Select for overlap — check the checkbox next to a roster to include it in "Find Time Together".
⚠️ Saved rosters are stored only on this browser. If you use a different phone/computer, you'll need to save the roster again on that device.

7. Finding Time Together 💞 crew sync

This is the main reason to save rosters — it finds overlapping free time between 2 or more crew members.

Step‑by‑step

  1. Save at least 2 rosters with different names (e.g., "Ikhlas" and "Nadiya").
  2. In the "Find Time 2B Together" section, check the boxes next to the crew members you want to coordinate.
  3. Tap "Find overlap". The tool will analyse all selected rosters.
  4. Results appear:
    • If you selected 3 or more, you'll see "All {N} together" — time when everyone is free.
    • Below that, you'll see pairwise breakdowns — overlap between each pair (e.g., Ikhlas × Nadiya).
    • Each result shows the date, time, location, duration, and whether it's Confirmed or Maybe (standby‑dependent).
  5. You can also tap "Heatmap view" to see a calendar with coloured bars — more visual.
  6. After computing, a new "Image" button appears in the toolbar – tap it to save a snapshot of the overlap results.

How the tool decides what's "free"

  • Off days (D, DO, EL) — completely free (confirmed).
  • Layovers (LO) — free time away from base (confirmed).
  • Gaps between duties — any time between report and debrief that isn't flying is counted as free.
  • Standby duties — marked as Maybe because you might be called in.
💡 If two people are in different locations (e.g., one in KUL, one in BKK), the tool only counts overlaps when they are both at the same station.

8. Heatmap View visual calendar

After running "Find overlap", tap "Heatmap view" to see a calendar‑like grid.

  • Each day is a small box.
  • The box is filled with a horizontal bar that shows free time from midnight (left) to midnight (right).
  • Green = time everyone is free together (confirmed).
  • Gold = time that depends on standby (maybe).
  • Red = not free.
  • Tap any box to see a popup that tells you who has to leave first for their next duty — useful if you're planning something and need to know when to wrap up.

To go back to the table, tap "Table view".

💡 The heatmap is especially handy when comparing multiple people's free time — during a gathering, it indicates who has to leave if it's not a full day off together.

10. Allowance Estimate 💰 cabin crew only

This feature gives you a rough estimate of your monthly allowance based on the parsed roster data. It calculates productivity + incentive + block‑hour excess + meal using the figures from the manual.

⚠️ The estimate is not official – it’s a tool to help you plan and understand your pay components. Always refer to your actual payslip for exact figures.

How to use it

  1. After loading and saving your roster, scroll to the “Calculate Allowance” button (near the bottom, above the overlap section).
  2. Tap it – the allowance card will expand.
  3. Select your grade (D1, E4, or E3) from the dropdown. The tool tries to auto‑detect it from your roster’s header, but you can override it manually.
  4. The estimate appears with a breakdown of each component and a grand total.
  5. If any station is unknown (i.e., not in the built‑in region map), you’ll see a prompt to assign a region – do that once, and the tool will remember it for future calculations.
  6. You can also tap the “Image” button that appears to save a snapshot of the allowance summary.

What each component means

ComponentHow it’s calculated
ProductivitySum of duty hours × grade‑specific rate (RM22, RM20, or RM18 per hour).
Only flying, positioning and airport standby (ASx) are counted – cabin crew standby (S3/S4) and training are excluded.
IncentiveSum of duty hours × flat RM7 per hour (same for all grades).
Block‑hour excessIf total block hours exceed 80h, the excess is multiplied by the grade‑specific rate (RM18, RM16, or RM15 per hour).
Meal allowanceFor each layover (rest gap >3h between flights of the same pairing), one meal (breakfast/lunch/dinner) is added per day based on the station’s region – using fixed regional rates. If a station is unknown, you’ll be asked to assign it.

Station region assignment

The tool has a built‑in map for most airports. If it encounters an unknown station (e.g., a new destination), it will:

  • Show a warning with a dropdown list of regions.
  • Choose the correct region – the assignment is saved locally, so you only need to do it once per station.
  • After assigning, the meal allowance will automatically update.
💡 The region determines meal rates – check the meal allowance rate table for accurate regions if you’re unsure.

Important notes

  • Only works for rosters that contain leg‑level data (i.e., rosters parsed after this feature was added). Older saved rosters (without the legs field) will show a message – just re‑parse and re‑save.
  • All calculations are estimates and may not perfectly match your actual payslip because of company‑specific policies (e.g., rounding, minimum hourly blocks, etc.).
  • The tool uses the duty hours and flight hours exactly as parsed – ensure your roster is loaded correctly before trusting the numbers.
⚠️ If you see “No leg‑level data available”, it means the current roster was saved before this allowance feature was added. Re‑upload the original file and save it again – then the estimate will work.

11. Troubleshooting help

Where to get my Excel .xlsx file?

  1. Log in to your Company's Roster Website "Download Excel".
  2. Use the XLSX version if available — it's much more reliable.
  3. If something goes wrong, click on "Export debug data" (near the bottom) and send that file to Zayn Ikhlas' Dad.

"Find Time Together" shows no results

  • The selected rosters might not have overlapping date ranges. Make sure the rosters are from the same month.
  • They might be at different stations (e.g., one in KUL, one in BKK) during the entire overlap.
  • Check that you have saved both rosters with the correct timezone setting (SLT).

My custom legend disappeared

⚠️ Legend changes are stored in your browser's local storage. If you clear browsing data (cache, cookies, site data), they'll be lost. To avoid this, don't clear site data for this page.

General tips

  • All processing is 100% offline — nothing is uploaded anywhere. Your privacy is protected.
  • If something looks wrong, refresh the page and try again.
  • For best results, use the latest version of Chrome, Safari, or Firefox.

12. About This Tool Why?

Why I built this

For the thousands of times I had to compare two rosters' timing from an image on my phone, calculating the time, figuring out the long or short streak of free time just to find when I could be with Her and Zayn Ikhlas.

I only have a phone, and I love portrait mode. I needed everything to fit on one screen because when you're scrolling through life on the go, you don't have time for landscape, and you don't have time for guesswork. The heatmap tells you exactly when you're both free and who has to leave first because that's the real question, isn't it?

So I built this for:

  • Couples figuring out "When are we both free?" and "How long do we really have?"
  • Friends planning group gatherings, just a single overlap would do if we're lucky.
  • Crew parents coordinating school runs and parking spots.
  • The 3-minute hugs during transit when your layover is on the opposite side of the map.

Over time, I added features my colleagues asked for: saving multiple rosters, classic styling, colours, no grainy, compressed images over WhatsApp, etc, which helps me too.

I hope it saves you as much time as it saves me because all I needed was those green bars in a sea of red cells. All code runs in your browser, so your data stays private. I welcome your feedback, it's the only way to improve things, so don't hesitate to text Alif and Fahrin.

Here's to fewer lonely calculations, and more 💚 bars.
