1. Getting Started first use

Loading a Roster File

  1. Drag & drop your roster file onto the dashed drop zone — or click "Choose file"
  2. Accepted formats: .xlsx .xls .pdf
  3. PDF files: The parser will auto-detect whether it's a Roster Report or Calendar/Fridge view
💡 XLSX is preferred — PDF parsing is still being improved. Use the "force re-parse" buttons if auto-detection fails.

What Happens After Loading

The page will:

  • Parse the file and extract all flight/activity data
  • Build a complete daily roster for the month
  • Calculate monthly statistics (block hours, duty hours, off days)
  • Display the Code Legend with descriptions

5. Saving Rosters storage

Why Save Rosters?

Saved rosters are required for the "Find Time Together" feature. They also let you keep a history of your schedules.

How to Save

  1. After parsing a roster, the "Save This Roster" section appears
  2. Enter a Crew name (your name or an identifier)
  3. Select a Timezone:
    • SLT — display in home base time (KUL +8)
    • UTC — display in Coordinated Universal Time
  4. Click "Save roster"

Managing Saved Rosters

ActionHow-To
View a saved rosterClick the View button
Delete a saved rosterClick the Delete button
Select for overlapCheck the checkbox next to a saved roster
⚠️ Saved rosters are stored locally in your browser. Clearing your browser data will remove them.

6. Find Time Together 💞 crew coordination

Purpose

Finds overlapping free time between 2 or more crew members. Useful for planning social activities, crew meetups, or coordinating schedules.

How It Analyzes

The system examines each crew member's saved roster and identifies:

  • Off days — completely free (D, DO, EL)
  • Layovers — free time away from base (LO)
  • Gaps between duties — free time before/after flights
  • Standby duty — marked as Maybe (not confirmed free)

Step-by-Step

  1. Save at least 2 rosters (see Section 5)
  2. Check the boxes next to the crew members you want to coordinate
  3. Click "Find overlap"
  4. Results appear showing:
    • All {N} together — time everyone is free (3+ members selected)
    • Pairwise breakdown — overlap between each pair of crew members

Result Color Coding

Confirmed together Maybe (standby-dependent) Everyone off all day

7. Heatmap View visual calendar

What It Shows

A calendar-style grid where each day's cell shows free time as a horizontal bar:

  • Left edge = 00:00 (midnight)
  • Right edge = 24:00 (next midnight)
  • Green = time everyone is free together
  • Gold = time that depends on standby availability
  • Red = time not available
💡 Consecutive-day overlaps line up at the cell boundary so a multi-day stretch reads as one continuous bar — perfect for spotting long free periods.

How to Use

  1. After running "Find overlap", click "Heatmap view"
  2. To return to the table view, click "Table view"

9. Troubleshooting help

PDF Parsing Issues

  1. Use XLSX if possible — it's the most reliable format
  2. Force re-parse — click "Roster Report table" or "Calendar / fridge" below the file name
  3. Export debug data — click the Export debug data button at the bottom and share the file for bug fixes

"Find Time Together" Shows No Results

  • Crew schedules may not overlap in the date range
  • Check that all selected rosters cover overlapping date periods
  • Ensure the "station" matches (e.g., both in KUL at the same time)

Legend Changes Disappeared

⚠️ Legend changes are saved in your browser's localStorage. If you clear your browser data, the legend resets to defaults.

General Tips

  • All parsing happens locally — nothing is uploaded
  • The "Fit screen" button helps with screenshots
  • Use "Print / PDF" for a clean printed version
